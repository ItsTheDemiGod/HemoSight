# Phase 2 - Sclera segmentation and sclera-referenced illuminant estimation

Generated by `scripts/illuminant_calibration_report_phase2.py`. Tests **N1a** and **N1b**, which after the Phase 1.5 restructure are the project's strongest claims.

> **Scientific premise.** The sclera is not a neutral white reference: it is slightly yellowish, varies with age, and carries red, spatially non-uniform vasculature. Every method here estimates the illuminant *given a surface with a known non-neutral reflectance prior*. Assuming neutrality is treated as one prior among several and is measured, not assumed away.

---

## 1. N1a - illuminant estimation accuracy across sensors (nus8)

nus8 has no eyes, so it isolates ESTIMATION error from SEGMENTATION error. The ColorChecker's neutral patches stand in for the reference surface: like the sclera they are *near*-neutral but not exactly neutral, so the prior ablation here predicts how well a sclera prior must be known.

Two protocol details are not optional:

* **Dark level subtraction.** Skipping it inflates Canon600D's mean angular error from ~0.9 to ~12 degrees. The `color.txt` values are raw sensor counts.
* **16-bit reading.** These PNGs are 16-bit; PIL silently truncates them to 8-bit, collapsing ~1800 distinct values to ~11. `cv2.IMREAD_UNCHANGED` is used.
* **Leakage control.** The ColorChecker is masked out of every classical baseline's input. It is the answer key.

### 1.1 The prior ablation - the number that predicts the sclera requirement

| prior on the reference surface | mean angular error |
| --- | --- |
| assumed neutral (naive white reference) | 1.266 deg |
| fixed population-average prior | **0.666 deg** |
| oracle per-image prior (not deployable) | 0.000 deg |

**Knowing the reference surface's true reflectance halves the error** (0.600 deg, 47%). The oracle reaching exactly 0.000 is not a meaningful achievable number - it is fitted per test image and is reported only to prove the measurement model inverts exactly, which means **all residual error is prior error, not model error**.

**This is the quantitative warning for N1b:** on a surface only mildly non-neutral, assuming neutrality doubles the error. The sclera is more non-neutral than a ColorChecker grey patch, so its prior matters at least this much.

### 1.2 Cross-sensor transfer

| method | per-camera 3-fold | leave-one-camera-out | degradation |
| --- | --- | --- | --- |
| fixed_population | 0.666 | 0.735 | +0.070 |
| neutral | 1.266 | 1.266 | +0.000 |
| oracle_per_image | 0.000 | 0.000 | +0.000 |

A prior fitted on five cameras and applied to a sixth barely degrades, so **the reflectance prior transfers across sensors** rather than encoding a camera-specific correction. That is the property calibration-free operation needs.

### VERDICT N1a: **SUPPORTED**

Criterion declared in advance: *reference-patch mean angular error beats every classical baseline*.

Reference-patch estimation with a fitted prior reaches **0.666 deg** against the best classical baseline's **3.076 deg** - a 4.6x reduction. It holds across all six sensors and survives leave-one-camera-out.

**Scope of this verdict.** N1a establishes that *given a correctly segmented reference patch of known reflectance*, illuminant estimation is accurate and transfers across sensors. It says nothing about whether the sclera can BE that patch - that is N1b.

### 2.4 Vasculature exclusion

Redness R/(G+B) above the 75th percentile *of each sclera* is dropped; a fixed absolute threshold would behave differently under each lighting condition.

* Sclera area removed: **25.0%**
* True vessels occupy 6.9% of the sclera (SBVPI ground truth, n=60)
* Recall of true vessel pixels: 0.404; precision 0.109

Precision is modest by design: the goal is a clean reference patch, so over-removing sclera costs little while retaining a vessel costs a haemoglobin-tinted reference - exactly the contamination this project cannot tolerate.

## 3. N1b - sclera self-consistency across devices and lighting

MOBIUS: 3 phones x 3 lighting conditions x 100 subjects, no haemoglobin needed. A subject's tissue has fixed reflectance, so after a correct illuminant correction the recovered colour should agree across conditions. Residual disagreement is the calibration error.

### 3.1 The circularity trap

Estimating the illuminant from the sclera and then measuring consistency ON the sclera is circular: `corrected = measured / (measured / prior) = prior`, a constant, so the spread collapses to exactly zero for every subject. That would look like a triumphant confirmation and would mean nothing.

**The primary evaluation region is therefore the IRIS** - a different surface with its own fixed per-subject reflectance, never used to estimate the illuminant. A secondary sclera figure uses a spatial holdout (estimate from one half, evaluate on the other) and is reported as partially circular.

### 3.4 The prior question - and why this experiment cannot answer it

| sclera prior | mean dE2000 spread |
| --- | --- |
| fixed_population | 7.4268 |
| neutral | 7.3115 |
| per_subject | 7.4268 |

The three priors differ by only **0.1153 dE2000**, and that is not a weak result - it is a mathematical necessity that this protocol cannot escape.

A prior is a constant for a given subject, so it multiplies every one of that subject's captures by the same factor. It therefore *shifts* the subject's colour cluster without changing its *spread*. **Self-consistency is blind to the reflectance prior.** It measures whether sclera-referencing removes capture-condition variation; it cannot measure whether the recovered colour is correct.

The prior question is answerable only where absolute ground truth exists: **N1a answers it on nus8** (halving the error, section 1.1), and **N1c will answer it against haemoglobin**. This is a limitation of the N1b protocol as designed, recorded rather than glossed.

A second, separate limitation: `per_subject` and `fixed_population` came out **bit-identical** (maximum per-subject difference 0.0). A per-subject prior can only be fitted from that subject's own ground truth, which held-out subjects by definition do not have, so the estimator falls back to the population value. **A per-subject prior is not evaluable in any deployable setting** - which is itself the answer to whether one could be shipped: it could not.

### 3.4b Is the difference real? Paired tests over subjects

The per-subject distributions overlap heavily, so the ranking is tested rather than eyeballed. Paired over the same n=40 held-out subjects; positive difference means the sclera method is WORSE.

| --- | --- | --- | --- |
| none | -2.104 | 2.4e-08 (**significant**) | 35/40 |
| grey_world | +1.351 | 3.1e-08 (**significant**) | 6/40 |
| shades_of_grey_p6 | -0.123 | 4.4e-01 (not significant) | 22/40 |
| max_rgb_p99 | -0.830 | 5.4e-06 (**significant**) | 32/40 |
| sclera_prior_neutral | +0.115 | 2.5e-01 (not significant) | 18/40 |

Read precisely, the sclera reference:

* **beats no correction** (p ~ 1e-8, better in 35/40 subjects) - it genuinely removes capture-condition variation;
* **beats max-RGB** (p ~ 5e-6);
* **ties shades-of-grey** (p = 0.44, indistinguishable);
* **loses to grey-world** (p ~ 3e-8, better in only **6 of 40 subjects**) - this is a real, consistent deficit, not sampling noise;
* and the fitted prior is **not significantly different from assuming neutrality** (p = 0.25), the empirical confirmation of the mathematical argument in 3.4.

### 3.5 Why the sclera reference underperformed a whole-image statistic

Three explanations are consistent with the evidence and are not mutually exclusive:

1. **Sample size of the reference.** Grey-world integrates millions of pixels; the sclera reference is a few thousand after vasculature exclusion, and is measured through a segmentation with IoU 0.875 rather than a perfect mask. A noisier reference gives a noisier illuminant.
2. **The fitted prior absorbed grey-world's bias, not sclera physics.** MOBIUS ships no ground-truth illuminant, so the prior had to be fitted against grey-world under a stated assumption. The recovered value is `[0.85798, 1.02006, 1.12197]` - **more blue than red**, which is the opposite of a yellowish sclera. MOBIUS frames are skin-dominated, so grey-world leans red, and the 'reflectance' inherited the inverse of that bias. This is a defect of fitting a prior without ground truth, and it is why the fitted prior scores marginally WORSE than assuming neutrality here.
3. **The iris is not a perfectly stable target either.** It is segmented at IoU 0.815 on MOBIUS and is partly specular, so some residual spread is measurement noise shared by all methods - which compresses the differences between them rather than favouring any one.

None of these rescues the claim. They say the experiment was fair and the result is informative, not that the result should be discounted.

## 5. Synthesis: the three results explain each other

Read together, N1a, the sensitivity analysis and N1b tell one coherent story, and it locates the bottleneck precisely.

1. **The estimation mathematics is not the problem.** Given a reference surface whose reflectance is known, illuminant estimation reaches 0.67 deg and transfers across six sensors (N1a).
2. **Segmentation accuracy is not the problem either.** Dilating or eroding the sclera mask by 31 pixels moves the estimate only 0.40 deg - smaller than the N1a prior gain.
3. **Knowledge of the sclera's own reflectance IS the problem.** A 10% yellowing shift - well inside normal inter-subject and age variation - moves the estimate by **4.40 deg**, larger than grey-world's entire error. Leaving vasculature in costs a further 1.57 deg.

So the sclera fails as a white reference not because it is hard to find or hard to measure, but because **its reflectance varies between people by more than the illuminant signal being estimated**, and that variation cannot be recovered per subject without ground truth the deployment setting will never have. A fixed population prior cannot absorb a per-subject quantity.

This is the most useful thing Phase 2 produced. It is a mechanistic explanation of a negative result, it was predicted by the phase's stated premise that the sclera is not neutral, and it says exactly where effort should go next.

### Constraints this places on later phases

* **Lighting, not device, degrades segmentation.** Sclera IoU spread across phones is only 0.0352, but across lighting it is 0.0973: 0.894 indoor versus **0.797 in poor light**. The pipeline degrades exactly where field deployment would operate, and any N1b or N5 result stratified by lighting inherits this confound.
* **The quality score is too weak for N4 as it stands.** It ranks deliberately-bad frames below good ones (AUROC 0.816) but their means differ by only 0.029, and **no bad frame falls below the 0.3 threshold**. As an abstention signal it currently rejects nothing. N4 will need a better non-conformity signal than this - the spectral reconstruction residual, as N4 already specifies.
* **Vasculature exclusion is crude.** Removing 25% of sclera area recovers only 40% of true vessel pixels at 11% precision, against vessels that occupy just 6.9% of the sclera. It is a blunt redness threshold, and SBVPI's 128 vessel masks are enough to train a proper vessel segmenter if Phase 4 needs one.
* **Iris segmentation does not transfer to SBVPI** (IoU 0.000 there versus 0.815 on MOBIUS): SBVPI annotates iris on only ~128 of 1,840 images, so the class is barely supervised in that domain. N1b is unaffected because it runs on MOBIUS, but any later use of the iris on another dataset must not assume this transfers.
* **The pipeline does run on Eyes-Defy** - mean quality 0.814, **0.0% failures**, and the two sites agree (0.811 India versus 0.816 Italy). Phase 4 has a working front end. Note this is a confidence measure, not accuracy: Eyes-Defy ships no masks, so correctness there is unverified.

### Verdicts

| claim | verdict |
| --- | --- |
| **N1a** - illuminant accuracy across sensors | **SUPPORTED** |
| **N1b** - sclera as endogenous white reference | **PARTIALLY SUPPORTED** |

**N1b is not softened and will not be retried until it passes.** The sclera does remove real capture-condition variation, but it does not beat a whole-image grey-world statistic on a held-out region, and the device effect survives correction. Under the criterion declared before the experiment ran, that is partial support, and the headline claim as originally written - that the sclera is a *sufficient* endogenous white reference - is **not** supported by this evidence.
