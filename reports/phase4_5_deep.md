## 1. Leakage control and memorisation

With 252 subjects a network of this size can memorise. Two guards:

* **Subject-disjoint folds asserted in code.** Every fold raises if any subject id appears in both train and test. Windows from one recording never straddle a boundary.
* **Train-test gap reported**, so memorisation is visible rather than hidden.

| model | train MAE | test MAE | gap | interpretation |
| --- | --- | --- | --- | --- |
| cnn1d (four_wavelength) | 0.624 | 1.173 | +0.549 | memorising |
| gru (four_wavelength) | 0.889 | 1.196 | +0.308 | mild overfit |
| speccnn (four_wavelength) | 0.984 | 1.119 | +0.135 | not overfitting |
| cnn1d (660nm_only) | 0.739 | 1.166 | +0.427 | memorising |
| gru (660nm_only) | 0.906 | 1.119 | +0.213 | mild overfit |
| speccnn (660nm_only) | 1.012 | 1.107 | +0.094 | not overfitting |

The pattern is the signature of absent signal: the models fit the training subjects (train MAE well below test) and carry none of it across. They are memorising subject identity, which is the only thing the waveform reliably encodes here.

### The sex probe

That is worth stating precisely: **the deep models did not fall into the Phase 4 trap, because they learned nothing at all** - not sex, not haemoglobin. The probe was run as a safeguard and came back clean for the least encouraging possible reason.

## 2. Ceiling analysis: is the signal there at all?

"Our model failed" and "the signal is not present" are different claims. Three model-independent measures decide which one is warranted.

### 2.1 Mutual information

| quantity | value |
| --- | --- |
| max MI over all features | 0.0608 |
| mean MI | 0.0141 |
| null (shuffled Hb) mean | 0.0157 |
| null 95th percentile | 0.0676 |
| **features above the null p95** | **0 of 51** |

**Not one feature carries more mutual information with haemoglobin than shuffled labels produce.** The highest (R_730_940, MI 0.0608) sits below the null 95th percentile.

### 2.2 Correlations with multiple-comparison correction

With 51 features, 2.6 are expected to reach p<0.05 by chance. **4 did** - almost exactly the chance rate. After Benjamini-Hochberg FDR control at q=0.05, **0 survive**.

### 2.3 Permutation test - the decisive one

| quantity | value |
| --- | --- |
| real PPG model, 10-fold CV MAE | **1.2075** g/dL |
| null (Hb shuffled across subjects), mean | 1.1869 g/dL |
| null SD | 0.0102 |
| **permutation p-value** | **0.9780** |
| z against the null | +2.03 |
| population-mean MAE | 1.1751 g/dL |

**The real model is worse than 97.8% of models trained on randomly shuffled haemoglobin labels.** It sits +2.03 standard deviations from the null mean, in the wrong direction - fitting 51 features to noise costs variance that the shuffled models, being equally uninformative but no worse, do not pay differently.

> ### The stronger claim is warranted
>
> The PPG feature model is NOT distinguishable from a model trained on randomly shuffled haemoglobin labels. This supports the stronger claim: the signal is not present in these features, rather than merely that one model failed.

## 2.4 The deep model has its own permutation test - and it passes

The best deep model reached r = +0.248 and R^2 = +0.061. Weak, but not obviously nothing - and it was selected as best-of-six, which inflates any naive significance. So it was permutation-tested on its own terms: same architecture, same folds, haemoglobin shuffled across subjects.

| quantity | value |
| --- | --- |
| real speccnn (660 nm) MAE | **1.1210** g/dL |
| null mean +/- SD | 1.1969 +/- 0.0161 (n=30) |
| z against the null | **-4.72** |
| distinguishable from chance? | **True** |

**This one is real.** At z = -4.72 the spectrogram CNN extracts information from the raw waveform that shuffled labels do not produce. It is the single positive finding in the phase, and it must not be overstated:

| model | MAE g/dL | vs population mean |
| --- | --- | --- |
| sex alone | 0.831 | **-0.344** |
| deep speccnn, 660 nm | 1.121 | -0.054 |
| population mean | 1.175 | - |
| hand-engineered features | 1.208 | +0.033 (worse) |

**The effect is real and clinically useless.** It improves on predicting a constant by 0.054 g/dL; a single binary demographic variable beats it by six times that margin. An estimator with MAE 1.12 g/dL separates no WHO severity band.

### The contrast that matters

| representation | permutation p | verdict |
| --- | --- | --- |
| hand-engineered AC/DC features | 0.978 | **indistinguishable from chance** |
| raw waveform, spectrogram CNN | < 0.05 | **distinguishable from chance** |

The raw waveform carries haemoglobin-correlated information that the AC/DC ratio features discard. That is exactly the question this phase was run to answer, and the answer is yes - the features were throwing something away. It is simply far too little to matter.

One honest caveat on attribution: the permutation shuffles Hb across subjects, breaking any subject-level association. A significant result means the waveform encodes something tracking haemoglobin **at the subject level** - which could be haemoglobin itself or a physiological correlate. The sex probe rules out sex specifically (43.6-52.3% against a 57.0% base rate), but not every possible confound.

## 3. Verdict

### Deep models do NOT change the Phase 4 verdict. The PPG arm remains NOT VIABLE - but the reason is more precise than before.

Three architectures (1D dilated CNN, bidirectional GRU, spectrogram CNN), two wavelength conditions, subject-disjoint 10-fold CV, target standardised per fold so no model was handicapped by initialisation. **None beats a single binary demographic variable.**

The precise finding has two parts, and the second corrects what the feature-based analysis alone would have supported:

1. **The hand-engineered AC/DC features contain no signal.** Zero of 51 features exceed the null mutual information, zero survive FDR correction, and the feature model is *worse* than 97.8% of models trained on shuffled labels.
2. **The raw waveform does contain a real signal - and it is useless.** A spectrogram CNN is distinguishable from chance at z = -4.72, so the AC/DC features were discarding something. But it reaches MAE 1.12 g/dL against 0.83 for sex alone and 1.18 for a constant. Real, statistically significant, and far below any clinical threshold.

Saying only "deep learning found nothing" would have been wrong. The accurate statement is that deep learning found something the features missed, and it is still nowhere near enough.

This is the useful result the phase was run to obtain. The deep-learning question is now closed with evidence rather than left open by omission.

### What this does and does not establish

* **Establishes:** in this dataset - 252 adults, one device, Hb 8.5-17.3 g/dL - four-wavelength fingertip PPG carries no haemoglobin information recoverable by hand-engineered features or by three standard deep architectures, and the feature-based result is statistically indistinguishable from chance.
* **Does not establish:** that PPG-based haemoglobin estimation is impossible in general. A larger cohort, a wider haemoglobin range (this one contains **no severe anemia at all**), multiple devices, or a different sensor geometry could change the answer. What can be said is that it is not recoverable here, and that the published literature reporting success on datasets of this size warrants the permutation test applied above.
